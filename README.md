# Wp-clone-website

This project is a **WhatsApp-inspired website clone** that I created while following a **Git and GitHub tutorial**. The main purpose of this project was to practice web development concepts along with learning how to use Git for version control and manage a project using GitHub.

## 📌 About the Project

The Wp-clone-website is a simple website designed to recreate some of the basic visual elements and layout of WhatsApp. It was developed as a learning project while exploring how websites are created, organized, updated, and maintained using Git and GitHub.

Through this project, I practiced creating a project structure, writing and modifying code, making changes, tracking those changes with Git, and uploading the project to a GitHub repository.

## 🎯 Purpose

The main goals of this project were:

- To practice basic web development
- To understand website layout and design
- To learn Git and GitHub fundamentals
- To understand version control
- To practice creating Git commits
- To learn how to push a project to GitHub
- To understand how a project can be managed using a Git repository

## 📚 What I Learned

While working on this project, I learned how to:
